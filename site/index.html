02 · AGENTIC SDLC ONTOLOGY

Five axioms that eliminate category errors

Agents rarely fail from missing prose steps; they fail by conflating session memory with code truth, single edits with coupled changes, or summaries with evidence.

  1. A1

    Reality Overrides Memory

    Fresh origin/main, real caller→constructor traces, STATUS.md, and live read-only probes override conversation memory and stale docs unconditionally.

  2. A2

    Coupled Artifact Closure

    Editing a primary node (code, API, schema) remains ontologically PARTIAL until coupled tests, contracts, docs, and STATUS.md sync — enforced by scripts/check-change-sync.py.

  3. A3

    Non-Collapsing State Machine

    NOT_RUN, UNKNOWN, RESULT_UNKNOWN, CONFLICT, and ERROR are first-class states; never collapse them into boolean true or fake defaults (?? 0, || []).

  4. A4

    Producer / Judge Separation

    The actor producing a patch never certifies its own gate changes. Protected GitHub Rulesets and independent mechanism review hold final merge authority.

  5. A5

    Asymmetric Knowledge Evolution

    Incidents graduate into failing negative tests and deterministic gates. Automated learning may only tighten constraints — never auto-expand permissions or remove approvals.

04 · WORKFLOW INTEGRATION

Five hook points — keep your existing tools

Keep Claude Code, Cursor, Codex, and superpowers for inner-loop coding. Attach deterministic guardrails only at the five handoffs where AI workflows fail.

01

Pick Up Task

Read unified root AGENTS.md + STATUS.md, branch in a fresh worktree, and block direct commits on main with workspace-git.py.

02

Plan & Code

Enforce non-trivial task gates (>3 files / >50 lines), secure-vibe-coding, and pre-coding reliability & performance invariants.

03

Before "Done"

Run check-change-sync.py, done-claim-verify, and audit-pr-diff — emit a DoneClaim with explicit does_not_prove[].

04

Open PR & CI

Run SHA-pinned fail-closed CI (Python/TS/Rust/Go/Java) + 4-line action.yml; cite OAS-* Rule IDs in review.

05

Merge & Launch

Enforce non-self-attesting GitHub Rulesets + CODEOWNERS, and run 5-dimension audit-production-readiness (H1/H2).

05 · SIX STANDALONE SKILLS & NINE STANDARDS

Language-agnostic guardrails, loaded on demand

Skills encode security, reliability, audit, and Git invariants — never formatting or language style rules. Every skill explicitly declares itself non-authoritative.

bootstrap-agentic-sdlc

Inspects your real stack and safely scaffolds unified AGENTS.md, thin @AGENTS.md CLAUDE.md, STATUS.md, PR templates, and fail-closed CI.

secure-vibe-coding

Enforces fail-closed auth/tenant scope, safe sinks, SSRF 169.254.169.254 defense, default-mutating tool manifests, read-only exfiltration blocks, and negative tests.

audit-pr-diff

Audits diffs with file:line grounding across Seven Sins, security red lines, 454-bug frontend traps, 8-class backend perf traps, and mechanism review.

audit-production-readiness

Full-repo 5-dimension audit enforcing 7 evidence disciplines, 3-layer defaults, data liveness, pre-release safety, asymmetric self-learning, and an H1 vs H2 verdict.

done-claim-verify

Refuses bare "done": true claims; preserves non-green states, dereferences 4 fake-done breakpoints, checks coupled sync, and requires does_not_prove[].

multi-agent-git-flow

Coordinates parallel agents via fresh remote baselines, isolated worktrees, Managed Issue Claims, cross-session handoffs, anti-stacked-PR rules, and safe cleanup.

Honest Limits (does_not_prove)

Markdown rules and Skills are ergonomic projections — never merge authority. PR-controlled CI and local audits remain candidate/advisory; payments, auth, runtime semantics, and P99 load still require real integration tests, protected GitHub Rulesets, and human engineering judgment.
