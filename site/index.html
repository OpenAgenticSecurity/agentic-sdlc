A REAL DAY WITH CODING AGENTS

5 exact hook points — keep your existing tools

Keep Claude Code, Cursor, Codex, and superpowers for inner-loop coding. Snap agentic-sdlc onto the 5 handoffs where AI workflows actually fail.

01

Pick Up Task

Read unified root AGENTS.md + STATUS.md, isolate in a fresh worktree from origin/main, and block direct commits on main with workspace-git.py.

02

Plan & Code

Enforce the non-trivial task gate (>3 files / >50 lines → plan + failing test first) and trigger secure-vibe-coding on auth, tenant scope, sinks, crypto & deps.

03

Before Saying "Done"

Run done-claim-verify + audit-pr-diff: dereference all 4 fake-done breakpoints and emit a DoneClaim with explicit does_not_prove[].

04

Open PR & CI

Run SHA-pinned fail-closed CI (Python/TS/Rust/Go/Java) + 4-line action.yml catching multi-language sinks and --passWithNoTests; cite OAS-* IDs in review.

05

Merge & Launch

Enforce non-self-attesting GitHub Rulesets (github-ruleset.import.json + CODEOWNERS) and run 5-dimension audit-production-readiness (H1/H2 verdict).

6 STANDALONE SKILLS · LANGUAGE-AGNOSTIC

Zero-overlap guardrails, loaded only on demand

Skills carry security, verification, audit, and Git invariants — not language formatting or style rules. Every skill explicitly declares itself non-authoritative.

bootstrap-agentic-sdlc

Inspects your real stack and safely scaffolds unified AGENTS.md, thin @AGENTS.md CLAUDE.md, STATUS.md, PR templates, and fail-closed CI without overwriting files.

secure-vibe-coding

Enforces default-deny auth/tenant isolation, parameterized queries, safe sinks, SSRF 169.254.169.254 defense, zero fallback secrets, anti-slopsquatting, and negative security tests.

audit-pr-diff

Audits diffs with file:line grounding across Seven Sins, Secure Vibe Coding, 454-bug frontend traps, 8-class backend performance traps, and enforcement-surface review.

audit-production-readiness

Full-repo 5-dimension audit (Architecture, Design, Functionality, Performance, Security) enforcing 7 evidence disciplines, 3-layer defaults, data liveness, and an H1 vs H2 verdict.

done-claim-verify

Refuses bare "done": true claims; preserves NOT_RUN/FAIL/ERROR/CONFLICT, dereferences 4 fake-done breakpoints, and requires DoneClaim + does_not_prove[].

multi-agent-git-flow

Coordinates parallel agents via fresh remote baselines, isolated worktrees, Managed Issue Claims, cross-session contract handoffs, anti-stacked-PR rules, and 5-point safe cleanup.

ZERO-TRUST & NON-SELF-ATTESTATION

Three-layer defense architecture

Prompt rules decay across context compaction. Real trust boundaries must live outside the model window.

LAYER 1 · NON-AUTHORITATIVE ERGONOMICS

Inside the Coding Agent

6 standalone Skills · llms.txt (~1K-token routing map) · unified root AGENTS.md + thin @AGENTS.md CLAUDE.md · 8 empirical checklists.

LAYER 2 · DETERMINISTIC LOCAL GUARDRAILS

On the Developer Machine

Zero-dep polyglot audit-repo.py (Python/JS/TS/Go/Rust/Java) · reversible Git hooks (workspace-git.py) · lockfile-keyed Node store · optional upcoming Rust carriers deps & sealed-data.

LAYER 3 · HARD MERGE BOUNDARY

External GitHub Enforcement (Not Self-Attesting)

SHA-pinned fail-closed CI (Python/TS/Rust/Go/Java) · Reusable action.yml · Enforcement-surface CODEOWNERS · Importable GitHub Ruleset JSON · Read-only observe-github-ruleset.py.

Honest Limits (does_not_prove)

  • Markdown rules and Agent Skills are ergonomic projections — they cannot stop determined prompt injection or replace human engineering judgment on payments, auth, or production ops.
  • PR-controlled CI jobs and local self-audits are always candidate / advisory — never self-attesting merge authority.
  • Static checks catch high-signal structural and supply-chain traps; runtime semantics and P99 load still require real integration tests and external controls.
